Mọi request đi qua frontend tới backend (/api/...) và gửi kèm tên đăng nhập, mật khẩu ở góc trên (header Authorization: Basic).

Bấm vào một API để mở. Sửa tham số hoặc body rồi bấm Gửi. request_id nhận được từ các API gửi việc sẽ tự điền vào các API cần nó.
